# Experiment 1: Dart Basics

## Aim
To understand the fundamentals of Dart programming.

## Description
This program demonstrates Dart basics using a student skill-sharing scenario from the SkillSwap application.

## Concepts Used
- Variables and data types
- Lists
- For loops
- Conditional statements
- Print statements

## Procedure
1. Create a Dart program.
2. Declare variables using different data types.
3. Create a list of skills.
4. Use a for loop to display the skills.
5. Use an if statement to check availability.
